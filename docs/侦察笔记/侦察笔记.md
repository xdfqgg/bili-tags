## 一、B 站推荐页 DOM 结构（实测）

### 视频卡片结构（推荐流 .feed2 内）

```
div.feed-card                            ← 流中的一格（注入时克隆这个）
 └─ div.bili-feed-card
     └─ div.bili-video-card.is-rcmd      ← 卡片本体
         └─ div.bili-video-card__wrap
             ├─ a.bili-video-card__image--link  → 封面图（picture/img），跳 /video/BVxxx
             ├─ .bili-video-card__info          → 标题 + 作者 + 播放/弹幕统计
             └─ .bili-video-card__no-interest   → B 站自己的「不感兴趣」按钮（克隆时删除）
```

### 关键实测数据

| 项 | 值 |
|----|-----|
| 推荐流容器 | `.feed2`（另有 `.container.is-version8` 外层） |
| 卡片选择器 | `.bili-video-card`（21 张骨架 + 滚动懒加载后 54 张真卡） |
| 视频链接格式 | `https://www.bilibili.com/video/BV1sv8B6ZEz7` |
| 封面图格式 | `https://i0.hdslb.com/bfs/archive/xxx.jpg@672w_378h_1c_!web-home-common-cover` |
| **重要** | 卡片是**懒加载骨架屏**：未滚动时是 `__skeleton` 空壳，滚到才渲染 → content script 注入时必须监听滚动后的新节点 |

## 二、B 站搜索 API 侦察（实测）

| 端点 | 结果 | 结论 |
|------|------|------|
| `api.bilibili.com/x/web-interface/search/type` | ❌ `-1200 被降级过滤` | 老端点已被反爬封死（带 cookie 也不行） |
| `api.bilibili.com/x/web-interface/search/all/v2` | ❌ `-1200` | 同上 |
| `api.bilibili.com/x/web-interface/wbi/search/type` | ✅ `code:0`（返回风控凭证 v_voucher） | **活着，但需要 wbi 签名** |
| `app.bilibili.com/x/v2/search` | ❌ `-400` | App 端接口需要另一套 App 签名，更复杂，放弃 |
| `api.bilibili.com/x/web-interface/nav` | ✅ 未登录也能返回 **wbi_img.img_url / sub_url** | **签名所需的密钥能免费拿到** |

### 结论：Step 7 的实现路线

1. 先调 `nav` 接口拿 img_key / sub_key（未登录即可拿）
2. 按公开的 wbi 签名算法：参数排序 → 拼 img_key+sub_key 混淆表 → 取前 32 位 → md5 → 附加 `w_rid` 参数
3. 带 buvid3 cookie + Referer + UA 调 wbi 搜索端点
4. 风险：B 站风控随时可能升级（v_voucher 机制暗示有二次校验）→ **手动 BV 清单降级必须保留**

## 三、MV3 manifest 要点（Context7 官方文档核实）

```json
{
  "manifest_version": 3,
  "host_permissions": ["https://*.bilibili.com/"],
  "permissions": ["storage"],
  "background": { "service_worker": "background.js", "type": "module" },
  "content_scripts": [{
    "matches": ["https://www.bilibili.com/*"],
    "js": ["content-script.js"],
    "run_at": "document_idle",
    "world": "ISOLATED"
  }]
}
```

要点：host_permissions 给 bilibili.com（background 跨域请求用）；content_scripts 的 `world: ISOLATED` 是默认隔离环境（与页面 JS 互不可见，配合 Shadow DOM 双层隔离）。

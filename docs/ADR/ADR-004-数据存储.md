# ADR-004：数据存储 —— chrome.storage.local

- 状态：✅ Accepted
- 日期：2026-08-23

## 背景

需要存储两类数据：① 标签配置（小而常读）；② B 站搜索结果缓存（每个关键词 Top 20 条视频，含封面 URL 等字段，体积不小）。需求文档已定「数据仅本地存储」。

## 决策

**chrome.storage.local**。

## 备选方案

| 方案 | 取舍 |
|------|------|
| `chrome.storage.sync` | 跨设备同步，但配额仅 100KB 且有限频，塞不下视频缓存 |
| 网页 `localStorage` | MV3 的 background service worker 环境中**不存在**此 API，排除 |

## 结果与影响

- 10MB 配额，纯本地，符合合规底线（不上传任何信息）
- 异步 API，读取要 `await` —— 代码结构上从第一天就按异步设计

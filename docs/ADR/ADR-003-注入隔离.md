# ADR-003：注入隔离 —— Shadow DOM

- 状态：✅ Accepted
- 日期：2026-08-23

## 背景

扩展要往 B 站推荐页注入视频卡片与标签 badge。B 站是重度定制样式的前端，存在**双向污染**风险：B 站的 CSS 命中注入元素（badge 面目全非）；注入的 CSS 泄漏到页面（改坏 B 站元素）。

## 决策

**Shadow DOM**：每个注入容器挂载到独立 shadow root，样式内外互不可见。

## 备选方案

| 方案 | 取舍 |
|------|------|
| 前缀类名（`.bilitags-`） | 实现简单，但只是**概率性**隔离 —— B 站改版新增同名类即可撞车 |

## 结果与影响

- 机制性隔离：双向污染从机制上杜绝，而非靠命名纪律
- 代价：多几行 `attachShadow` 代码
- 兼容性：Shadow DOM 是 Chrome 原生能力，扩展只跑 Chrome，无顾虑

# ADR-000：平台选型 —— Chrome 扩展（曾考虑手机 App）

- 状态：✅ Accepted
- 日期：2026-08-23

## 背景

项目目标：把用户按标签关键词选好的视频卡片，随机混入 B 站推荐流。开发进行到技术选型阶段时，用户提出改为手机 App，理由是「网页扩展使用的人太少」。

## 决策

**继续 Chrome 扩展（Manifest V3）路线。**

## 备选方案与被否决理由

| 方案 | 否决理由 |
|------|---------|
| 独立手机 App（React Native / Flutter） | 核心机制「向第三方内容注入 UI」在移动端不成立：系统沙盒禁止 App 修改其他 App 界面。产品将变形为独立视频流 App，丧失核心价值；开发量 ×3–5，已批准计划作废 |
| 移动浏览器油猴脚本 | 保留注入机制，但用户需安装特殊浏览器，门槛高于扩展 |

## 结果与影响

- 产品形态固定为浏览器扩展，核心价值（混入推流）完整保留
- 「用户量少」的担忧记录在案：MVP 阶段第一个用户是用户本人，验证想法后再考虑分发
- 未来若做手机端，将作为独立项目重新立项（API 层/缓存/标签逻辑可复用）

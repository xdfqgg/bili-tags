# ADR-001：语言选型 —— TypeScript

- 状态：✅ Accepted
- 日期：2026-08-23

## 背景

扩展有三个代码入口：content script（注入逻辑）、background（API 请求层）、options 页（配置 UI）。项目强依赖两个**外部结构**：B 站 API 响应结构、B 站页面 DOM 结构 —— 二者均由第三方控制，随时可能变更。

## 决策

**TypeScript**：为 API 响应与 DOM 结构定义 `interface`，编译期校验。

## 备选方案

| 方案 | 取舍 |
|------|------|
| 纯 JavaScript | 零配置、直接运行；但接口/DOM 变更要到运行期才发现，与本项目「对抗外部结构变化」的核心风险不匹配 |

## 结果与影响

- 需要一层编译（由 esbuild 承担，见 ADR-002）
- 外部结构变更时编译期报错，风险前移：改版了编译器先告诉你哪里断了
- Chrome API 有官方 `@types/chrome` 类型包，开发体验提升
